# SOLID — A cidade é de quem manda nela

Landing page do jogo SOLID, publicada pelo GitHub Pages.

Um jogo de crime e sobrevivência numa cidade litorânea em blocos 3D. Você chega
sem nada além do aluguel do hotel pra pagar, e a rua oferece um jeito rápido de
resolver isso — cobrando caro depois.

## Sobre este repositório

Só a página. Fica em `index.html`, sem build, sem dependência: HTML, CSS e um
pouco de JavaScript, abertos direto no navegador.

```
landing/
├── index.html     a página inteira
├── trailer.mp4    o vídeo do trailer
└── img/           logo e capturas do jogo
```

## Ver localmente

Abra o `index.html` no navegador — não precisa de servidor.

## Publicar

O GitHub Pages serve esta pasta. Em **Settings → Pages**, escolha a branch
`main` e a pasta `/ (root)`.

## Créditos

Todos os direitos reservados.
